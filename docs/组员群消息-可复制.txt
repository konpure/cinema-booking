【本地模式】
  需要：JDK17 + MySQL + Redis + Erlang27 + RabbitMQ + Node18
  1. docker/start-rabbitmq.ps1
  2. backend 复制 application-local.yml.example → application-local.yml，填 MySQL 密码
  3. backend/run-backend.ps1
  4. frontend 里 npm install && npm run dev
  访问 http://localhost:5173
