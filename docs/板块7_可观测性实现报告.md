### 做了什么

给系统接入了三套可观测性技术：

**① Logback 日志系统**
- 写了 `logback-spring.xml`，日志同时输出到三个地方：控制台、滚动文件、Logstash
- 日志文件按天切分、按大小切分（100MB），保留30天
- Logstash 走 TCP 发送结构化 JSON 日志（带应用名、线程名、日志级别等字段）

**② Elasticsearch 日志栈（ELK）**
- 配好了 Logstash 管道（接收日志 → 按级别分类 → 写入 ES）
- docker-compose 里加了 Elasticsearch、Logstash、Kibana 三个服务
- 启动后后端日志自动流入 ES，Kibana 上就能查

**③ Prometheus 指标监控**
- 加了 `micrometer-registry-prometheus` 依赖
- 暴露了 `/actuator/prometheus` 端点，实时输出 **519 个指标**
- 涵盖 JVM内存、GC、线程、Tomcat、数据库连接池、RabbitMQ、Spring Security 等
