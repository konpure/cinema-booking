## 三、RabbitMQ 在哪开？（重要）

本项目后端连接 `localhost:5672`，**必须先启动 RabbitMQ**，否则后端无法启动。

### 方式一：项目自带脚本（推荐）

```powershell
cd "你的路径\cinema-booking\docker"
.\start-rabbitmq.ps1
```

- 会弹出一个 **CMD 黑窗口**，显示 RabbitMQ 日志
- **这个窗口不能关**，关了 MQ 就停
- 脚本成功后会提示：`[OK] RabbitMQ started! port 5672`
- 管理界面：http://localhost:15672 ，账号 `guest` / `guest`

### 方式二：手动启动

```powershell
# 需已安装 Erlang 27.x + RabbitMQ 4.x（不要用 Erlang 29）
set ERLANG_HOME=C:\Program Files\Erlang OTP
cd "C:\Program Files\RabbitMQ Server\rabbitmq_server-4.3.1\sbin"
rabbitmq-server.bat
```

### 验证 RabbitMQ 是否在跑

```powershell
Test-NetConnection localhost -Port 5672
```

### RabbitMQ 在项目中的作用

1. 用户**购票成功后**，后端同步创建订单
2. 同时向队列 `cinema.order.queue` 发送 **OrderNotification** 消息
3. `OrderConsumer.java` 异步消费并写日志（答辩可演示管理台队列消息）

## 四、本地完整启动顺序

```powershell
# 0. 确保 MySQL(3306)、Redis(6379) 已运行

# 1. RabbitMQ（保持 CMD 窗口不关）
cd cinema-booking\docker
.\start-rabbitmq.ps1

# 2. 后端
cd ..\backend
$env:DB_PASS="你的MySQL密码"   # root 无密码则省略
.\run-backend.ps1

# 3. 前端（新窗口）
cd ..\frontend
npm install    # 首次
npm run dev
# 浏览器 http://localhost:5173
```

**演示账号：** `demo` / `demo123` · `admin` / `admin123`

**若数据库是旧版结构**：重启后端会自动迁移列；若仍缺影城/卖品数据，可 `DROP DATABASE cinema;` 后重启后端自动重建。
