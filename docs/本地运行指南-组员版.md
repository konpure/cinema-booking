# 本地运行指南（组员版）

> 拿到小组作业 zip 包并解压后，按本文从零跑通项目。  
> 默认 **不用 Docker**，Windows + PowerShell 即可。

---

## 0. 解压后先看目录

解压后应类似：

```
cinema-booking-发给组员/          （或你解压后的文件夹名）

├── frontend/                     前端
├── docker/                       RabbitMQ 启动脚本等
└── docs/                         技术报告、分工文档
```

以下命令里的路径，请改成**你本机解压后的实际路径**。

## 1. 安装环境（首次必做）

| 软件 | 作用 | 检查方式 |
|------|------|---------|
| **JDK 17** | 运行后端 | `java -version` 显示 17 |
| **MySQL 8** | 数据库 | 服务已启动，端口 3306 |
| **Redis** | 座位锁 | 端口 6379 可连 |
| **Erlang 27.x** | RabbitMQ 依赖 | 不要用 Erlang 29 |
| **RabbitMQ 4.x** | 消息队列 | 端口 5672 可连 |
| **Node.js 18+** | 运行前端 | `node -v`、`npm -v` |

### 快速检查三服务端口（PowerShell）

```powershell
Test-NetConnection localhost -Port 3306   # MySQL
Test-NetConnection localhost -Port 6379   # Redis
Test-NetConnection localhost -Port 5672   # RabbitMQ
```

`TcpTestSucceeded : True` 表示该服务可用。

也可在项目里运行：

```powershell
cd docker
.\check-local.ps1
```

## 2. 配置 MySQL 密码（只需做一次）

后端默认用户 `root`，密码需**你自己配置**（不会写在压缩包里）。

```powershell
cd backend
copy src\main\resources\application-local.yml.example src\main\resources\application-local.yml
```

用记事本打开 `application-local.yml`，改成你的 MySQL 密码，例如：

```yaml
spring:
  datasource:
    username: root
    password: "你的MySQL密码"
```

保存后关闭。

> 说明：首次启动后端会自动创建数据库 `cinema` 和表，**一般不用手动建库**。  
> 若 MySQL 用户不是 `root`，同时修改 `username` 即可。

## 3. 启动顺序（每次运行项目）

需要 **3 个窗口**（或 3 个 PowerShell 标签页）。

### 窗口 1：RabbitMQ

```powershell
cd docker
.\start-rabbitmq.ps1
```

- 若提示 `already running on port 5672` → 已在跑，可直接下一步
- 若弹出 CMD 黑窗口 → **不要关**，关了 MQ 就停
- 管理台：http://localhost:15672（`guest` / `guest`）

### 窗口 2：后端

```powershell
cd backend
.\run-backend.ps1
```

成功标志：日志里出现

```text
Using profile: local (application-local.yml)
Started CinemaApplication
```

验证：浏览器打开 http://localhost:8080/actuator/health 有 JSON 返回。

### 窗口 3：前端

```powershell
cd frontend
npm install          # 仅第一次需要，较久
npm run dev
```

浏览器打开：**http://localhost:5173**

## 6. 常见问题

### 后端报 `Access denied for user 'root'`

- 检查 `application-local.yml` 密码是否与 MySQL 一致  
- 确认 MySQL 服务已启动  

### 后端报 Redis / RabbitMQ 连接失败

- Redis：确认 6379 端口通  
- RabbitMQ：先执行 `docker/start-rabbitmq.ps1`  

### 前端能开，但登录/接口报错

- 确认后端已启动且 http://localhost:8080/actuator/health 可访问  
- 必须用 `npm run dev`，不要直接打开 `dist/index.html`  

### 没有影城 / 卖品 / 场次数据

1. 确认后端已成功启动过一次（会自动插入演示数据）  
2. 仍异常时，MySQL 执行 `docs/init-local-db.sql` 重置库，再重启后端  

### `npm install` 很慢

- 可配置 npm 镜像：`npm config set registry https://registry.npmmirror.com`  

### Erlang / RabbitMQ 版本不对

- RabbitMQ 4.x 需要 **Erlang 27**，不要用 Erlang 29  
- 详见 `docs/本地启动指南-无Docker.md`
