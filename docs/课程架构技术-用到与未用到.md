## 二、已用技术 — 用在哪里

### 1. Spring Security ✅

| 用途 | JWT 登录、角色权限（USER / ADMIN） |
|------|-----------------------------------|
| 依赖 | `backend/pom.xml` |
| 安全配置 | `backend/src/main/java/com/cinema/config/SecurityConfig.java` |
| JWT | `backend/src/main/java/com/cinema/security/JwtUtil.java` |
| 过滤器 | `backend/src/main/java/com/cinema/security/JwtAuthFilter.java` |
| 401/403 JSON | `JsonAuthEntryPoint.java`、`JsonAccessDeniedHandler.java` |
| 登录业务 | `backend/.../service/AuthService.java` |
| 接口 | `backend/.../controller/AuthController.java` |
| 前端 | `frontend/src/views/Login.vue`、`frontend/src/api/index.js`、`frontend/src/router/index.js` |

---

### 2. Redis ✅（Redis / Memcached 二选一）

| 用途 | 分布式座位锁、防超卖、占座 TTL 自动释放 |
|------|----------------------------------------|
| 依赖 | `backend/pom.xml` → `spring-boot-starter-data-redis` |
| 配置 | `backend/src/main/resources/application.yml` → `spring.data.redis` |
| 配置类 | `backend/.../config/RedisConfig.java` |
| 核心逻辑 | `backend/.../service/RedisSeatService.java` |
| 调用 | `BookingService.java`（锁座/提交）、`OrderService.java`（释放锁） |
| 前端展示 | `frontend/src/components/SeatMap.vue`、`frontend/src/views/Booking.vue` |
| Docker | `docker/docker-compose.yml` → `redis` 服务 |
| 本地 | 本机 Redis 6379；脚本 `docker/start-rabbitmq.ps1` 同目录有 `check-local.ps1` |
| 测试 | `backend/src/test/java/com/cinema/RedisSeatServiceTest.java` |

**可用性：** 场景 A 抢票高峰防超卖；场景 B 占座超时自动释放。

---

### 3. MQ / RabbitMQ ✅（MQ 总类 + RabbitMQ/Kafka 二选一）

| 用途 | 购票成功后发送异步订单通知（削峰/解耦演示） |
|------|---------------------------------------------|
| 依赖 | `backend/pom.xml` → `spring-boot-starter-amqp` |
| 配置 | `application.yml` → `spring.rabbitmq`（含消费重试 3 次） |
| 队列配置 | `backend/.../config/RabbitMQConfig.java` |
| 消息体 | `backend/.../mq/OrderNotification.java` |
| 生产者 | `backend/.../service/BookingService.java` → `publishOrderNotification()` |
| 消费者 | `backend/.../mq/OrderConsumer.java` |
| Docker | `docker/docker-compose.yml` → `rabbitmq`（5672 / 15672） |
| 本地 | `docker/start-rabbitmq.ps1` 启动本机 RabbitMQ |
| 管理台 | http://localhost:15672（guest/guest） |

**说明：** 订单**同步**写入 MySQL（保证用户立即可查），RabbitMQ 负责**异步通知**链路演示。  
**可用性：** 场景 A 削峰；场景 B 消息重试。

---

### 4. Nginx ✅

| 用途 | 统一入口、托管前端静态页、反向代理 `/api` |
|------|------------------------------------------|
| 配置 | `docker/nginx/nginx.conf` |
| 镜像 | `docker/Dockerfile.nginx`（构建前端 + Nginx） |
| 编排 | `docker/docker-compose.yml` → `nginx` 服务，对外 **80** 端口 |

**本地开发**不走 Nginx，前端 `npm run dev` 通过 Vite 代理到 8080。

---

### 5. 负载均衡 ✅（清单独立项）

| 用途 | 两个后端实例分流，故障实例自动剔除 |
|------|-----------------------------------|
| 配置 | `docker/nginx/nginx.conf` → `upstream cinema_backend` + `least_conn` |
| 实例 | `docker-compose.yml` → `backend-1`、`backend-2` |
| 验证 | 多次访问 `GET /api/health`，`instance` 字段在 `cinema-backend-1/2` 间变化 |
| 实现 | `backend/.../controller/HealthController.java` |

**可用性：** 场景 B 实例短时故障转移（`max_fails=2 fail_timeout=10s`）。

---

### 6. Docker ✅

| 用途 | 单机集成部署：MySQL + Redis + RabbitMQ + 双后端 + Nginx |
|------|--------------------------------------------------------|
| 编排 | `docker/docker-compose.yml` |
| 后端镜像 | `backend/Dockerfile` |
| 前端+Nginx | `docker/Dockerfile.nginx` |
| 数据库初始化 | `docker/init.sql` |
| 组员启动 | `cd docker` → `docker compose up -d --build`（需 Docker Desktop） |
| 文档 | `docs/Docker-Toolbox-部署指南.md`、`docs/本地启动指南-无Docker.md` |

**说明：** 组长本机 VirtualBox/Docker Toolbox 有问题，用**本地模式**开发；**组员用 Docker** 跑完整栈。

---

### 7. Vue 3 ✅（前端技术选一种）

| 用途 | 用户端 SPA：选影城、购票、卖品、订单、管理后台 |
|------|-----------------------------------------------|
| 依赖 | `frontend/package.json` |
| 入口 | `frontend/src/main.js` |

| 组件 | `frontend/src/components/`（NavBar、MovieCard、SeatMap） |

| 构建 | `frontend/vite.config.js` |

### 8. ECharts ✅（HighCharts / ECharts 二选一）

| 用途 | 管理后台票房柱状图、热门影片饼图 |
|------|--------------------------------|
| 依赖 | `frontend/package.json` → `echarts` |
| 页面 | `frontend/src/views/Admin.vue` |
| 数据接口 | `backend/.../controller/AdminController.java` → `stats()` |
| SQL | `backend/.../mapper/OrderMapper.java` → `revenueByDay()`、`topMovies()` |

---

### 9. SLF4J / Logback ✅（日志工具选一种）

| 用途 | 统一日志格式，记录锁座、下单、MQ 消费等 |
|------|----------------------------------------|
| 依赖 | Spring Boot 自动引入 |
| 配置 | `application.yml` → `logging.level`、`logging.pattern` |
| 业务日志 | `@Slf4j`：`RedisSeatService`、`BookingService`、`OrderService`、`OrderConsumer` 等 |
| 异常 | `GlobalExceptionHandler.java` |

---

### 10. JUnit ✅

| 用途 | Redis 座位锁逻辑单元测试 |
|------|-------------------------|
| 依赖 | `backend/pom.xml` → `spring-boot-starter-test` |
| 测试类 | `backend/src/test/java/com/cinema/RedisSeatServiceTest.java` |

## 三、未用技术 — 为什么没用 / 在哪提到

| 技术 | 状态 | 原因 / 文档位置 |
|------|------|----------------|
| **Shiro** | ❌ 未用 | 与 Spring Security 功能重叠，已选 Security |
| **ZooKeeper** | ❌ 未用 | 单体 + 双实例，无需分布式协调 |
| **Hybrid Flask** | ❌ 未用 | 后端技术栈为 Spring Boot |
| **数据库读写分离** | ❌ 未用 | 报告扩展项，`docs/技术总结报告.md` 第五节 |

| **HighCharts** | ❌ 未用 | 与 ECharts 二选一，已选 ECharts |
| **Sentinel** | ❌ 未用 | 报告扩展项；组员任务 T4 可后续加限流 demo |
| **Nacos** | ❌ 未用 | 报告扩展项；当前非微服务注册架构 |
| **Kafka** | ❌ 未用 | 与 RabbitMQ 二选一，已选 RabbitMQ |
| **Kubernetes** | ❌ 未用 | 课程要求单机集成演示，Docker Compose 足够 |
| **Memcached** | ❌ 未用 | 与 Redis 二选一，已选 Redis |
| **Prometheus** | ❌ 未用 | 仅有草稿 `docker/prometheus/prometheus.yml`，**未**加入 `docker-compose.yml`，后端未暴露 `/actuator/prometheus` |

## 四、两种运行方式与技术对应

| 运行方式 | 谁用 | 能演示的架构技术 |
|---------|------|-----------------|
| **Docker Compose** | 组员（推荐） | Docker、Nginx、负载均衡、MySQL/Redis/RabbitMQ 容器、双后端、完整集成 |
| **本地模式** | 组长 / 无 Docker 同学 | Spring Security、Redis、RabbitMQ、Vue3、ECharts、SLF4J、JUnit（Nginx/负载均衡/Docker 看配置文件讲解） |

## 五、可用性场景 ↔ 技术映射

| 场景 | 问题 | 用到的技术 | 关键位置 |
|------|------|-----------|---------|
| **A 抢票高峰** | 超卖、接口压力大 | Redis 锁座、RabbitMQ 异步通知、Nginx 负载均衡 | `RedisSeatService.java`、`BookingService.java`、`nginx.conf` |
| **B 实例故障** | 单节点宕机、占座不释放 | Nginx 故障转移、MQ 重试、Redis TTL | `nginx.conf`、`application.yml`、`RedisSeatService.java` |

## 六、小组分工建议（每人 ≥3 项已用技术）

| 已用技术 | 建议讲解内容 | 主要文件 |
|---------|-------------|---------|
| Spring Security | 登录流程、JWT、ADMIN 权限 | `SecurityConfig.java`、`AuthController.java` |
| Redis | 锁座原理、TTL、防超卖 | `RedisSeatService.java` |
| RabbitMQ | 队列、购票后异步通知 | `RabbitMQConfig.java`、`OrderConsumer.java` |

| ECharts | 管理端图表 | `Admin.vue` |
| SLF4J | 日志配置与业务日志 | `application.yml`、各 Service |
| JUnit | 座位锁测试 | `RedisSeatServiceTest.java` |

**未用技术**（Sentinel、Nacos、ES、读写分离、Prometheus 等）可在报告**第五节「规划扩展」**中写设计思路，答辩时说明「时间有限未实现，架构上预留扩展点」。
